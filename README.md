# スマホの耳 👂　会話を文字に

耳が聞こえにくい人と家族が会話するための、音声リアルタイム文字起こしアプリです。
スマホのブラウザで開くだけで使えます（インストール不要）。

## できること

- 🎤 話した言葉を**すぐに大きな文字**にする
- 🔎 聞き取りのまちがいを直し、句読点をつけて**読みやすい文**にする
- ❓ **語尾の抑揚（声の高さ）**を調べて、質問かどうかを見分ける
- 🌏 話した言葉を**他の言語に翻訳**する
- 🧭 その言葉の**意図**と**返信の案**を出す（押すと読み上げます）
- 👥 **家族のスマホをつないで**、話した文字を全員の画面に出す
- 🙋 **誰の言葉を自分の画面に出すか**を、ひとりひとりが選べる

## 使い方

1. リンクを開く
2. 緑の「きく（スタート）」を押して、マイクを「許可」する
3. ふつうに話しかける

家族をつなぐときは、右上の「👥 グループ」→「新しく作る」→「🔗 招待リンクをコピー」で、
できたリンクを家族に送ってください。開いた人は自動で同じグループに入ります。

## プライバシーについて

- 音声そのものは**この端末の外に出ません**。文字にしてから扱います。
- グループでやりとりする文字は、**合言葉から作ったカギで暗号化してから**送られます
  （AES-GCM 256bit／PBKDF2）。中継所や第三者は中身を読めません。
- 合言葉は招待リンクの `#` より後ろに入っており、**サーバーには送信されません**。
- 翻訳を選んだときだけ、その文だけが翻訳サービスに送られます。
- **招待リンクは家族以外に送らないでください。** リンクを持つ人だけが会話を読めます。

## 動作環境

iPhone は Safari、Android は Chrome を推奨します。
マイクを使うため、`https://` で開く必要があります。

---

自宅のPC内だけで完結させたい場合は、同梱の `serve.py` を使うと
インターネットを一切経由しない「おうちモード」で動きます。
